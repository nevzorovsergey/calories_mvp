# Готовность интерфейса: что должно работать и чем проверено

Карта требований PRD → проверок. Смысл документа в том, чтобы «интерфейс
работает» было утверждением с доказательством, а не ощущением.

Три уровня проверок, каждый ловит свой класс поломок:

| Уровень | Команда | Что ловит |
|---|---|---|
| Браузер | `npm run test:ui` | Экран не открылся, компонент упал при гидратации, кнопка не нажимается, ввод не доходит до состояния |
| Сервер + БД | `npm run test:flow` | Не записалось то, что должно; RLS пускает лишнего; вьюхи считают не то |
| Типы и сборка | `npm run typecheck && npm run build` | Ошибки, видимые до запуска |

Браузерные тесты гоняются в **WebKit на профиле iPhone 14** — PRD целится в
Safari iOS (§14), и проверять надо там же. Любая ошибка в консоли браузера
роняет тест: именно этот класс поломок раньше проходил мимо проверок «страница
отдала 200 и нужный текст в HTML есть».

## Что намеренно не покрыто браузерными тестами

- **Реальный вызов модели** — в `flow.spec.ts` маршрут подменяется. Настоящий
  вызов проверяют `npm run test:flow` (сервер) и `npm run test:ui:live`
  (браузер), оба платные.
- **Установка PWA на домашний экран, вырезы и жестовая полоса** — это поведение
  системного браузера, эмулятор его не воспроизводит. Проверяется руками на
  устройстве.
- **Контраст и корректность при системном увеличении шрифта** — требует
  визуальной проверки; автоматизировать имеет смысл, когда интерфейс устоится.
- **Тёмная тема** — тесты идут в светлой. Переключение делается системой, а не
  приложением, и ломаться там нечему, кроме цветовых токенов.

## Как это гонять

```bash
npm run test:ui            # браузерные тесты (бесплатно, ~3 минуты)
npm run test:ui:headed     # то же, но видно, что происходит
npm run test:ui:live       # + настоящий вызов модели (платно)
npm run test:flow          # серверный сквозной тест (платно, ~3 ₽)
```

Тесты создают и удаляют собственных пользователей и приёмы пищи, поэтому
безопасны для базы с реальными данными. Отчёт с трассировкой падений —
`e2e/report/index.html`.
